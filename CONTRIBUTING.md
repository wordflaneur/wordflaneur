# Contributing

Thank you for wanting to contribute!

Guidelines:
- Fork the repo and create a feature branch: `git checkout -b feat/short-description`
- Keep commits focused and with descriptive messages.
- Add tests for behavior changes; run `npm test`.
- Open a pull request describing the change and motivation.
- Be respectful and follow the project's Code of Conduct.

Code style:
- Use consistent formatting and linting; run `npm run lint` before submitting.

If you plan to make infra or secrets-related changes, coordinate with maintainers to avoid exposing keys.
